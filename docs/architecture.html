Sync vs Async pipeline
Set mode: sync (default) or mode: async in your YAML. Async mode enables native async/await at every stage — no application code changes needed.
Sync pipeline
mode: sync (default)
  • Sequential stage execution
  • Embedding batches run one after another
  • Use pipeline.query() and pipeline.ingest()
  • Sync streaming via stream_query()
  • Works anywhere — scripts, CLI, Jupyter
  • No event loop required
Async pipeline
mode: async
  • Native async/await at every stage
  • Embedding batches run concurrently via asyncio.gather
  • Use await pipeline.async_query()
  • Live token streaming via astream_query()
  • Per-collection locks for parallel multi-collection ingest
  • Designed for FastAPI, async servers, high-throughput
